# Contributing

Thanks for helping keep this roadmap accurate and useful.

- Open an issue for a broken link, outdated course section, factual correction, or a gap in a module. Include a source when possible.
- For a pull request, keep the nine-module order and the concise **Learn / Course / Must-read / Hands-on** structure. Prefer primary course pages, paper pages, and official project repositories.
- For a new resource, state the exact chapters or lectures, why it improves the existing selection, and the expected learning outcome. Replace weaker links instead of growing an unbounded list.
- Keep all learner-facing text in English. Check Markdown links, headings, and table formatting before submitting.
- Do not commit credentials, private data, large model weights, or third-party material you cannot redistribute.

Contributions to the original roadmap text are offered under the repository's [CC BY 4.0 license](LICENSE). External resources retain their own terms.
